01 — PUBLIC SCOPE

누구에게 무엇을 보여주는가

대상은 불특정 대중입니다. 공개해도 안전하며 나를 설명하는 데 필요한 내용만 공개합니다.

대상과 목적: 불특정 대중에게 내가 어떤 사람이고 무엇을 좋아하며 어떤 경험이 있는지 보여주되, 직접 식별 정보와 비밀값은 공개하지 않습니다.

공개할 것

  • 경험·활동과 그 과정
  • 공개 가능한 강점·취향
  • 개인정보를 제거한 결과물과 근거

공개하지 않을 것

  • 주소·전화번호 등 직접 식별 정보
  • 비밀번호·토큰·API 키·시크릿
  • 타인의 공개 허가를 받지 않은 정보

05 — QUALITY CHECK

실제 결함 검사

검수표의 PASS를 미리 선언하지 않고, 실제 검사 결과를 기록합니다.

두 기준 화면

  • 1366 × 768
  • 1920 × 1080
  • 가로 넘침 0건
  • 첫 화면 핵심 3개 확인

링크·키보드·제목

  • 모든 링크 목적지 확인
  • Tab 순서 확인
  • h1 → h2 → h3 확인
  • Enter / Space 확인

명암·콘솔

  • 일반 글자 4.5:1 이상
  • 큰/굵은 글자 3:1 이상
  • 브라우저 콘솔 빨간 오류 0건

보안·공개 범위

  • 공개 금지 정보 0건
  • password / token / api key / secret 검색
  • Git 기록까지 비밀값 확인

짧은 확인 방법 4줄

  2. 3단계 이내 행동: 새 시크릿 창 → 주소 접속 → 소개 항목 선택
  3. 통과 모습: 소개·활동·근거가 보이고 소개 항목이 마우스/키보드로 펼쳐짐

AI와 나의 판단 3줄

  • AI에게 맡긴 일: HTML 구조 초안, 반복적인 검사와 개선안 제안
